# OpenTune Mobile 🎵 (UI & Wireframe Project)

**OpenTune Mobile** adalah aplikasi pemutar musik berbasis mobile yang dikembangkan menggunakan **Flutter**. 

**CATATAN PENTING UNTUK PENGEMBANGAN:** 
Proyek ini dikerjakan khusus untuk memenuhi syarat Ujian Tengah Semester (UTS) mata kuliah Pemrograman Berbasis Mobile. Oleh karena itu, proyek ini **MURNI HANYA BERFOKUS PADA DESAIN UI DAN WIREFRAME**. Tidak ada koneksi database, API, atau backend. Semua data yang tampil di aplikasi ini menggunakan **data statis (dummy data)**.

## 🛠️ Teknologi yang Digunakan
- **Flutter** (Framework)
- **Dart** (Bahasa Pemrograman)
- **Data Statis / Dummy Data** (Tanpa Database)

## 📌 Ruang Lingkup Tugas: User & Profile (Nazril Adrian)
Untuk modul ini, fokus pembuatan UI mencakup:
1. **Navigasi Utama:** Custom Bottom Navigation Bar.
2. **Layar Autentikasi:** Halaman Login dan Register (dengan navigasi sederhana, tanpa validasi server).
3. **Layar Profil:** Halaman yang menampilkan data profil pengguna secara statis.
4. **Layar Edit Profil:** Halaman form edit profil lengkap dengan tumpukan gambar (Stack) untuk foto profil.

Seluruh UI akan menggunakan *styling* warna ungu OpenTune dan memanfaatkan susunan widget dasar Flutter seperti `Column`, `Row`, `Stack`, dan `Positioned`.
